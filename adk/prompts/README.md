# Prompt Index

This folder stores English prompt templates used by the workflow.

## Prompt order

- `00_system.md` - global behavior rules,
- `01_requirements.md` - requirements extraction,
- `02_planning.md` - task planning,
- `03_generate_code.md` - code generation or modification,
- `04_generate_text.md` - thesis or paper text generation,
- `05_review_response.md` - response to feedback,
- `06_figures.md` - figures, diagrams, and charts.

## Usage note

Keep prompts short, explicit, and easy to reuse. Every prompt should say what input it expects and what the agent should output.
