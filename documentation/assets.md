# Assets and Visual Material

## Role of visual elements

The project may generate diagrams, charts, figures, and illustrations to explain technical or scientific content.

## Requirements for assets

Each generated visual should include:

- a clear title,
- a description or caption,
- a source or provenance note,
- consistency with surrounding text,
- a clear relationship to the described system or result.

## Provenance handling

The system should track:

- whether the asset was generated by AI or created manually,
- what prompt or source was used,
- whether the asset was reviewed or revised,
- how it connects to the project narrative.

## Quality standard

A figure should not be accepted unless it is coherent with the text and project content. This reduces the risk of mismatch between the technical description and the visual material.
